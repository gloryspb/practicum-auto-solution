# Автоматизация получения решения в Яндекс Практикуме

Файл `practicum-auto-solution.user.js` делает весь сценарий в браузере:

1. ждёт загрузки задания;
2. нажимает `Проверить`, пока не появится кнопка `Решение`;
3. нажимает `Решение`;
4. подтверждает окно `Посмотреть решение`;
5. вытаскивает образцовое решение из финального окна;
6. копирует его в буфер обмена;
7. закрывает уведомления/ошибки поверх текущего редактора;
8. пытается вставить код обратно в редактор Monaco или CodeMirror;
9. закрывает окно решения;
10. нажимает `Проверить` уже с правильным решением;
11. нажимает кнопку `Далее`, когда она становится доступна.
12. ждёт загрузки следующего задания и повторяет цикл.

На страницах с несколькими кодовыми блоками скрипт обрабатывает только блоки с кнопкой `Проверить`.
Демонстрационные редакторы, где есть только `Запустить код`, пропускаются.
Если открылась страница без задания, скрипт нажимает доступную кнопку перехода/действия и продолжает цикл.

Остановить цикл можно кнопкой `Stop` в статусном окне или командой в консоли:

```js
practicumAutoSolutionStop()
```

## Вариант 1: Tampermonkey

1. Установите расширение Tampermonkey.
2. Создайте новый userscript.
3. Вставьте содержимое `practicum-auto-solution.user.js`.
4. Сохраните.
5. Откройте страницу задания Практикума.

Скрипт запускается автоматически на адресах вида:

```text
https://practicum.yandex.ru/trainer/*
```

## Вариант 2: разовый запуск из консоли

1. Откройте страницу задания.
2. Нажмите `F12` -> вкладка `Console`.
3. Вставьте содержимое `practicum-auto-solution.user.js`.
4. Нажмите `Enter`.

После выполнения последнее найденное образцовое решение будет лежать в:

```js
window.__practicumLastSampleSolution
```

Повторный ручной запуск без перезагрузки страницы:

```js
practicumAutoSolution()
```
